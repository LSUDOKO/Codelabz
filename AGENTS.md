# Codelabz

Codelabz

Package manager: npm.

## Commands

- dev: `npm run dev`
- build: `npm run build`
- test: `npm test`
- lint: `npm run lint`
- format: `npm run format`

## Layout

- `ISSUE_TEMPLATE/`
- `cypress/`
- `designs/`
- `functions/`
- `public/`
- `src/`
- `testdata/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
